# Lessons index

Approved lessons live here as `L-*.md` (frontmatter: id, title, type, status, agents, triggers, evidence, severity, hits).
Candidates wait in `PENDING/`; rejected/retired ones in `RETIRED/`. Humans decide with `sfsmiths-human lessons review|approve|reject|promote|retire`
or from the UI; `sfsmiths-human learn` regenerates `.claude/skills/lessons-<agent>/SKILL.md` (capped by `config/learning.yaml → inject_cap`).
